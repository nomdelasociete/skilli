From a file to a command

Keep it. Run it.

  1. Read the code, then download. A skillie is a script that runs on your Mac. Check its requirements and what it changes before adding it.
  2. Double-click the .skilli file. skil.li shows the whole skillie, where it came from and every line of its code. Press Return to add it. Nothing runs yet.
  3. Run it. Find it in the launcher by its title. Fill in any arguments and press Return. You can also assign a shortcut or ask your agent to run it.

Rather do it by hand? In skil.li, open Settings → Skillies → Show in Finder and move the file there.

Writing your own? The skillies docs cover every header key, how a skillie runs and every tool it can call.

Made by you. Useful to someone else.

Pass the skill along.

Ask your agent to create a skillie with skil.li’s create_skillie tool. Review its code, then share the script from your skillies folder. It’s a file, not a subscription.

Share directly

Rename the script to end in .skilli and send it. A double-click shows it to them whole in skil.li before they add it.

Propose it for the collection

Add your script to the repository’s skillies/ folder and open a pull request. Once reviewed and merged, it appears here automatically.
