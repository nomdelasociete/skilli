# Logo 3D — v2 (12 octobre 2026)

Version figée, tag git `brand-3d-v2`. Plis ronds (demi-ellipse a = 38, b = 69,1 ; rayon de bord 21),
verre clair « liquid glass » épais de 8 avec biseau arrondi de 10 sur tous les bords, dispersion
(trois couches de verre R/V/B), sphère en verre clair.

Tout est là pour la retrouver telle quelle : scripts, scène `.blend`, GLB, HDR, PNG transparents,
rendus, viewer three.js et gabarit de la page de comparaison. `README-3d.md` est la doc de l’époque.
