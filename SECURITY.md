# Security

Report a vulnerability privately: GitHub's **Report a vulnerability** on the
[Security tab](https://github.com/nomdelasociete/skilli/security), or
contact@nomdelasociete.com. Please do not open a public issue.

Say what is affected, how to reproduce it, and what it lets someone do. You
will get an answer within a few days, and credit in the release that fixes
it if you want it.

Supported: the latest release (skil.li updates itself).
