## Known gaps

- The launcher's glass material and dark appearance are only verifiable on a
  real screen: off-screen snapshots approximate the glass and render light
  only, and a transparent panel cannot be captured with its backdrop without
  Screen Recording. Settings is captured from the window server, sidebar
  included.
- First launcher show is slower than warm shows (20–35 ms vs ~9 ms).
- With synthetic events, Raycast's Hyper Key keeps adding ⌘⌃⌥⇧ to keys typed
  right after a Hyper+Space that opened the launcher. Not seen with skil.li's
  own Hyper; check by hand with the real keyboard: ✦Space, release, type.
- If skil.li crashes after installing Caps Lock → F18, Caps Lock stays remapped
  until the next quit or reboot (the next launch detects and owns it).
- Event taps receive nothing while Secure Input is on (password fields,
  some terminals): no shortcut works then, in skil.li or any other app. The
  status menu says so and names the app that turned it on; a Hyper whose
  release was hidden lets go when Secure Input ends.
- Bindings can shadow Hyper shortcuts the user defined in Raycast (e.g.
  `✦ Space`); configurable bindings will fix this. Other apps' global
  hotkeys cannot be read (no API): only macOS's and the launcher's keys are
  checked when recording.
- The self-test steals focus and types: never run it while someone is using
  the Mac (its focus guard aborts, but keys typed meanwhile still land in the
  test window).
- Electron apps were not covered by the self-test (none safe to drive here);
  they go through the ⌘C fallback when AX exposes no selection.

### Live access account binding (pending release)

Relay pairing, restored credentials and renewed access require the authority’s authenticated computer subject to match the native token’s `/user` ID. Account switches and late identity responses cannot re-enable a previous session. Legacy unbound stream tokens fail closed; periodic GitHub reads remain available. Requires the authority `/computers/identity` endpoint before client rollout. Verified with session regression tests and compile-only Xcode builds; real two-account GitHub testing is still pending.
